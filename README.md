# data

Machine-generated output. The trackers that produce this branch live on
[`src`](https://github.com/wavedevgit/discord-datamining_v2/tree/src).

Every file here is rewritten by
[`mine.yml`](https://github.com/wavedevgit/discord-datamining_v2/blob/src/.github/workflows/mine.yml)
on a five-minute schedule. Do not edit by hand — the next run overwrites it.

Raw access:

```
https://raw.githubusercontent.com/wavedevgit/discord-datamining_v2/data/<file>
```
